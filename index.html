🤖 MT Chatbot Demo

This is the demo page for MT Chatbot, an AI-powered chatbot widget built with Hugging Face Inference API.

🚀 Quick Setup

  1. Get a Hugging Face API Key:
    • Sign up at Hugging Face
    • Go to Settings > Access Tokens
    • Create a new token with read access
  2. Initialize the chatbot
    <script src="chatbot.js"></script> <link rel="stylesheet" href="chatbot.css"> <script> MTChatbot.init({ apiKey: 'YOUR_API_KEY_HERE', model: 'mistralai/Mistral-7B-Instruct-v0.1', position: 'bottom-right' }); </script>

📋 Available Models

  • mistralai/Mistral-7B-Instruct-v0.1 - Fast & Good Quality (Recommended)
  • HuggingFaceH4/zephyr-7b-beta - Conversational
  • meta-llama/Llama-2-7b-chat-hf - General Purpose
  • tiiuae/falcon-7b-instruct - Fast Inference

⚙️ Configuration Options

{ apiKey: 'YOUR_HUGGING_FACE_API_KEY', model: 'mistralai/Mistral-7B-Instruct-v0.1', position: 'bottom-right', // bottom-left, top-left, top-right title: 'Chat with AI', placeholder: 'Ask me anything...', theme: 'light' // or 'dark' }

🔒 Security Notes

⚠️ Never commit your API key to version control. Use environment variables or pass it securely.
  • Store API keys in GitHub Secrets for GitHub Pages
  • Use a backend proxy for production deployments
  • Never expose your API key in frontend code

📚 Integration with Jekyll (GitHub Pages)

Add to your _includes/chatbot.html:

<script src="https://cdn.jsdelivr.net/gh/christoph-LSN/MT_Chatbot@main/chatbot.js"></script> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/christoph-LSN/MT_Chatbot@main/chatbot.css"> <script> MTChatbot.init({ apiKey: 'YOUR_HUGGING_FACE_API_KEY', model: 'mistralai/Mistral-7B-Instruct-v0.1' }); </script>

Then include in your layout:

{% include chatbot.html %}
